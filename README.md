# Inkubator Bayi Otomatis Berbasis IoT
 
Inkubator bayi yang menjaga suhu secara otomatis: DHT22 membaca suhu, ESP32 mengatur 4 pemanas lewat relay sesuai berat dan umur bayi, dan datanya dipantau lewat IoT.
